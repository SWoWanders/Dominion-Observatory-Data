# Gallery images

Put gallery image files in this folder.

- Name each file after its gallery id: `GAL-007.jpg`, `GAL-008.jpg`, ...
- Point the entry's `imageUrl` at `assets/gallery/GAL-007.jpg` in `js/gallery.js`.
- Keep the original, full-size file if you can; the page scales it.
